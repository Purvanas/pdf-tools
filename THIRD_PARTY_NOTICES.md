# Composants tiers

Ce dépôt embarque des versions minifiées afin que l'outil reste utilisable sans étape de build :

- **PDF.js 3.11.174** (`public/libs/pdf.min.js`, `pdf.worker.min.js`) — Mozilla, licence Apache-2.0 : <https://github.com/mozilla/pdf.js>
- **pdf-lib** (`public/libs/pdf-lib.min.js`) — Andrew Dillon et contributeurs, licence MIT : <https://github.com/Hopding/pdf-lib>

Les avis de licence inclus dans les bundles sont conservés. Ces fichiers ne sont pas relicenciés par la licence MIT du code propre au projet.
